# Library Management System using Java Swing

## About the Project

The Library Management System is a desktop-based application developed using Java Swing. It provides a graphical user interface to manage basic library operations, including student registration, book management, book returns, and viewing student details.

The project was developed to simplify library management activities through a user-friendly interface.

## Technologies Used
- Java
- Java Swing
- VS Code

## Features
- **Student Login:** Access the application using student ID.
- **Student Registration:** Register new students.
- **Add Book:** Add books to the library records.
- **Return Book:** Manage book return operations.
- **View Students:** Display registered student details.
- **User-Friendly Interface:** Simple graphical interface for library operations.

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Make sure Java and the Java Extension Pack are installed.
4. Open the main Java file.
5. Run the application.
